# 圈见 品牌资源

标志 = 一个**真实数据画出来的 15 分钟等时圈**（取自璧山样例的 16 方向可达半径：南长、西南短），三层嵌套对应 5 / 10 / 15 分钟，中心朱砂点是"见"的视点。不是圆，因为产品要说的就是"真实可达范围不是圆"。

| 文件                                                               | 用途                                    |
| ------------------------------------------------------------------ | --------------------------------------- |
| `logo-mark.svg` / `icon-512.png` / `icon-192.png`                  | 纯标（透明底），头像、应用图标          |
| `../favicon.svg` / `../favicon-32.png` / `../apple-touch-icon.png` | 网站图标（纸底圆角）                    |
| `logo-horizontal.svg/.png`                                         | 横版组合（浅底），README、PPT、文档页眉 |
| `logo-horizontal-dark.svg/.png`                                    | 横版组合（墨底），视频片头、深色背景    |
| `og.svg/.png`                                                      | 社交分享图 1200×630                     |

颜色：墨 `#23261f`、纸 `#f3ede0`、青 `#1f6e6a`、朱砂 `#c0391d`。字体：宋体系（Songti / Noto Serif CJK）做字标，等宽做拼音。
最小使用尺寸：纯标 16px（favicon 已验证可辨），横版 120px 宽。别把圈改成正圆，别换掉朱砂中心点。
