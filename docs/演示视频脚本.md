# 圈见 · 3 分钟演示视频分镜脚本

> 大赛要求提交演示视频。目标时长 3:00 ± 10 s，1080p，30 fps，全程录屏 + 旁白，不出镜。旁白语速约 240 字/分钟，总字数控制在 700 字以内。录制前用 `bash scripts/demo.sh` 起干净环境并预热一次缓存（避免录制中限流），录制时使用 `noCache` 关闭以展示真实耗时。

## 准备清单

- [ ] 浏览器 1920×1080，隐藏书签栏，缩放 100%
- [ ] `.env` 已填真实 AK，`ALLOW_SAMPLE_FALLBACK=false`
- [ ] 提前打开三个标签页：首页、GitHub 仓库 README、GitHub Actions 页
- [ ] 样例地址：`重庆市璧山区璧城街道`（lng 106.2277, lat 29.5921）
- [ ] 第二个对比地址（路网阻隔明显的，如临江或铁路旁社区）：_录制前确定_
- [ ] 录屏工具：OBS，麦克风降噪；或 ffmpeg `-f x11grab`

## 剪辑要点

- 镜头 3 等待算路的空档不剪掉，让评委看到真实耗时与进度反馈；若超过 8 s 用 2× 加速并加角标。
- 镜头 4 的百分比、镜头 6 的评级要与画面一致，录完对照测试报告核对旁白。
- 全片不出现 AK：录制前检查地址栏、终端、`.env` 编辑器都不在画面内。
- 字幕用画面底部单行，字号 ≥ 36 px；术语首次出现时字幕标注英文（isochrone、route matrix）。
- 导出：`ffmpeg -i raw.mkv -c:v libx264 -crf 20 -preset slow -c:a aac -b:a 128k demo.mp4`，控制在 200 MB 内。
