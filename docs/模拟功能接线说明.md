# 「假如在这里新建一处 X」模拟 —— 接线说明

本功能的算法、hook、面板、图层已全部完成并通过 typecheck / lint / test，**尚未接进 AppShell / MapView / TopBar**（这三处由主 Agent 接线）。本文列出接线需要做的每一步。

## 已交付文件

| 文件                                    | 作用                                                                                                                                   |

## 1. AppShell 状态

```tsx
import { useSimulate } from '@/lib/ui/useSimulate'
import SimulatePanel from '@/components/simulate/SimulatePanel'

const sim = useSimulate(state.report) // 报告换了会自动清空
const [simOpen, setSimOpen] = useState(false) // 面板开关
const [printReport, setPrintReport] = useState<HealthReport | null>(null) // 打印用的报告覆盖
```

- `sim.virtuals`：拟建列表；`sim.placing`：放置模式选中的类别（`null` = 不在放置模式）
- `sim.result`：`{ report, diff } | null`（无拟建设施时为 `null`）
- 关闭面板时请同时 `sim.setPlacing(null)`，避免用户关了面板还在"点地图放设施"

## 2. MapView：放置模式下点击 = 放设施，而不是改中心点

MapView 新增三个 props（建议命名）：

```ts
placing: FacilityCategory | null
virtuals: VirtualFacility[]
onPlaceVirtual: (category: FacilityCategory, p: LngLat) => void
onRemoveVirtual: (id: string) => void
```

在现有的地图点击 effect 里分流（`placing` 通过 ref 读取，避免重复绑定事件）：

```tsx
const placingRef = useRef(placing)
placingRef.current = placing
const placeRef = useRef(onPlaceVirtual)
placeRef.current = onPlaceVirtual

useEffect(() => {
  if (!map) return
  const handler = (e: BMapGL.MapEvent) => {
    const p = eventLngLat(e)
    if (!p) return
    if (placingRef.current)
      placeRef.current(placingRef.current, p) // 放置模式
    else centerChangeRef.current(p, 'click') // 原逻辑
  }
  map.addEventListener('click', handler)
  return () => map.removeEventListener('click', handler)
}, [map])
```

然后挂图层：

```tsx
import { useVirtualPoiLayer } from '@/components/map/useVirtualPoiLayer'
useVirtualPoiLayer(map, virtuals, onRemoveVirtual)
```

放置模式的视觉提示（可选但推荐）：`placing` 非空时给地图容器加 `cursor: crosshair`，并把 `aria-label` 改成"放置模式：点击放置拟建设施"。

**盲区 / 分数用模拟后的数据渲染**：把传给 MapView 的 `blindSpots` 改为
`sim.result?.report.blindSpots ?? state.report?.blindSpots ?? null`，地图上的盲区网格会随放置即时消失。
POI 列表不需要换（拟建点由 `useVirtualPoiLayer` 单独画，真实 POI 不变）。

AppShell 里对应：

```tsx
<MapView
  …
  blindSpots={sim.result?.report.blindSpots ?? state.report?.blindSpots ?? null}
  placing={sim.placing}
  virtuals={sim.virtuals}
  onPlaceVirtual={sim.addVirtual}
  onRemoveVirtual={sim.remove}
/>
```

## 3. 面板挂在哪

面板是无定位的受控组件（`className` 由父级给），两种挂法任选：

**A. 地图左下浮层（桌面推荐，与 PoiCard 同位置，PoiCard 打开时二选一）**

```tsx
{
  simOpen && state.report && (
    <SimulatePanel
      className="map-ui no-print absolute left-4 bottom-4 z-[var(--z-overlay)] w-[22rem] max-h-[calc(100dvh-8rem)]"
      report={state.report}
      virtuals={sim.virtuals}
      result={sim.result}
      placing={sim.placing}
      onSetPlacing={sim.setPlacing}
      onRemove={sim.remove}
      onUndo={sim.undo}
      onClear={sim.clear}
      onClose={() => {
        setSimOpen(false)
        sim.setPlacing(null)
      }}
      onExport={onExportSimulated}
    />
  )
}
```

移动端把 `left-4 bottom-4 w-[22rem]` 换成 `inset-x-3 bottom-[calc(bottomInset+12px)]`，或直接放进抽屉（方案 B）。

**B. 放进报告抽屉**：在 `Drawer` 里 `ReportPanel` 上方渲染，`className` 留空即可，此时不需要 `map-ui / absolute`。

**入口按钮**：TopBar 加一个「模拟新建」按钮（`canPrint` 同条件：有报告才可用），点击 `setSimOpen(true)`；
或者在 ReportPanel 的建议区每条"建议增设 X"旁加"去模拟"按钮 → `setSimOpen(true); sim.setPlacing(category)`。

图例（MapLegend）建议加一行"拟建设施（模拟）"：朱砂虚线圆 + 说明"1 km 虚线圈为盲区判定半径"。

## 4. 打印：导出模拟结果到 PDF

`SimulatePanel` 的 `onExport(simulated)` 只把**模拟后的 HealthReport** 交回父级。父级：

```tsx
const onExportSimulated = (simulated: HealthReport) => {
  setPrintReport(simulated)    // 抽屉临时显示模拟报告
  setDrawerOpen(true)
  window.setTimeout(() => window.print(), 120)
}

// afterprint 里清掉覆盖（现有 printing 状态的 effect 中追加）
const after = () => { setPrinting(false); setPrintReport(null) }

// Drawer 内容
<ReportPanel report={printReport ?? state.report} … />
```

模拟后的报告 `warnings` 已自动带一句"含 N 处拟建设施（模拟）"，`ReportPanel` 现有的 warnings 渲染会把它印在 PDF 上；`pois` 里拟建点 `name` 形如"拟建菜市场 ①"，`uid` 以 `virtual:` 开头（`isVirtualPoi(poi)` 可判），若报告里有 POI 清单可据此加"拟建"角标。

如果希望屏幕上也能"切换查看模拟后的完整报告"，同样用 `printReport ?? state.report` 的思路，加一个"查看模拟报告 / 回到原报告"的开关即可，不需要改算法层。

## 5. 数据流回顾

```
地图点击(placing≠null) → sim.addVirtual(category, p)
   → 立即按直线估算入列(pending) → fetch /api/walk → 回填 walkSec/walkM/source
   → useMemo applyVirtualFacilities(report, virtuals)   // 纯前端，~1 ms
   → sim.result.diff 驱动面板；sim.result.report.blindSpots 驱动地图盲区层
```

服务端只在每次放置时被调一次（一对点的 routematrix），其余全部本地重算。

## 6. 注意

- `useSimulate` 监听 `report.id`，重新体检会自动清空拟建列表；若主 Agent 在 mock 模式下复用同一个 report 对象，也是同样行为。
- `applyVirtualFacilities` 幂等：把模拟后的报告再传进去不会重复计入拟建点。
- 拟建点 marker 的 click 会触发 `onRemove`；在放置模式下点到已有拟建点上会移除而不是新增（Baidu 的 marker click 不会冒泡到 map click）。
- `useVirtualPoiLayer` 里 1 km 判定圈 `enableClicking: false`，放置模式下圈内继续点地图能正常放置。
