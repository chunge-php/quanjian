# 圈见 · 服务器部署（standalone 包，宝塔 / 任意 Linux）

包里已含编译产物与精简依赖，服务器只需 **Node 20**，不用 pnpm、不用 build。

## 1. 上传解压
```bash
mkdir -p /www/wwwroot/quanjian && cd /www/wwwroot/quanjian
unzip -o quanjian-<版本号>.zip
```

## 2. 写运行配置
```bash
cp .env.example .env && nano .env
```
只需改：`BAIDU_SERVER_AK=你的服务端AK`，`ALLOW_SAMPLE_FALLBACK=true` 保持。
浏览器端 AK 在打包时已编进前端，这里不用再填。

## 3. 启动（二选一）
**pm2（推荐）**
```bash
npm i -g pm2
pm2 start ecosystem.config.cjs && pm2 save && pm2 startup
```
**宝塔 Node 项目管理器**：项目目录选本目录，启动文件 `server.js`，端口 3010，运行方式 production，
环境变量粘贴 `.env` 内容（或勾"读取 .env"）。

验证：`curl http://127.0.0.1:3010/api/health` 返回 `"hasServerAk":true`。

## 4. 反向代理 + HTTPS（宝塔）
站点 → 反向代理 → 目标 `http://127.0.0.1:3010`，配置文件的 `location /` 里加：
```
proxy_buffering off;
proxy_read_timeout 600s;
proxy_http_version 1.1;
```
（不加会卡住街道体检的实时进度）。SSL 页签申请证书，开强制 HTTPS。

## 5. 百度控制台
浏览器端 AK → Referer 白名单加 `*.你的域名/*`；服务端 AK 的 IP 白名单含服务器 IP（或 0.0.0.0/0）。

## 6. 更新版本
本地 `pack <新版本>` → 上传 zip → 解压覆盖（`.env` 不会被覆盖）→ `pm2 restart quanjian`。
磁盘缓存在 `data/cache/`，可随时删。
